# Art Direction Brief — Game of Mboa

Procedural, layered 2D characters. No AI-looking defaults. Cameroon colour and street scale.

## Palette
- Ground: deep greens (#1b5e20, #2e7d32)
- Dirt roads: browns (#5d4037, #6d4c41)
- Accents: mboa yellow (#f9a825), maquis red (#c62828)
- Night: #0d1b2a

## Character layers
shadow → shoes → legs → torso → arms → head → eyes → hair → name tag

Debrouillard = warm orange streetwear. Connecte = cool blue.

## Rules
- Prefer hand-tuned Phaser Graphics over generic stock
- Labels in Camfranglais where natural
- District vibes visible in ground tint and landmarks
