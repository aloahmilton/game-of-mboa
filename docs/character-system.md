# Character System — Game of Mboa

## Dual mode
- Anonymous / quick: procedural layered body (PlayerVisual)
- Realistic / custom: same layers + skin, hair, clothes options later

## Classes
- debrouillard — start low money, street energy
- connecte — higher start money, status path

## Control
Keyboard (WASD), touch joystick, manette (Gamepad API). Offline mode moves client-side.
